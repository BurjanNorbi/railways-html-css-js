# 🚂 Vasútépítő – Interaktív HTML játék

Ez a projekt egy egyszerű, böngészőben futtatható vasútépítő játék, amelyet tisztán HTML, CSS és JavaScript felhasználásával készítettem, külső keretrendszerek nélkül. A játék célja, hogy a játékos egy körbeérő vasútvonalat építsen a megadott pályán, különböző tereptípusokat figyelembe véve (hegy, híd, oázis stb.). A pályák véletlenszerűen generálódnak a választott nehézségi szint szerint. A játékmenet időre megy, a játék végén toplista készül, és az eredmények, valamint az állás elmenthetők a böngésző LocalStorage-ába.

## Fő funkciók

- Teljesen reszponzív

- Elemlehelyezés kattintással vagy vonalhúzással

- Szabályellenőrzés: körbejárás, elérhetőség, elemtípusok

- Toplista és időmérés minden nehézségi szinten

- Mentés és betöltés automatikusan LocalStorage-ból
